Angel Engine

TACTICAL GRID COMBAT · UNITY / C# · 7-PERSON TEAM · U-TAD · 2025–2026

For our final-year team project I worked on both sides of combat: I designed the fights and wrote the code that runs them. Every enemy shares one base class, every ability is built from data, and every dangerous tile is shown to the player before it hurts.

My role was Lead Programmer & Combat Designer in a team of seven. This page follows the systems in the order the game uses them: the grid, the abilities that act on it, and the enemies and bosses that use them. Each part has footage or screenshots from the build.

01

A Grid That Remembers Danger

GridManager builds a grid of Tile objects at runtime from a width and a height. In the game the board is eight columns by four rows, split in two halves: blue tiles on the player's side and red tiles on the enemy's side. Each tile knows if it is occupied and how dangerous it is right now.

When an ability targets a tile, it raises that tile's danger level before the damage lands. Enemies, and eventually players, use that information to read the board and decide where to move. Danger is part of the grid itself, not a visual effect added on top. What you see and what the AI reads are the same data.

02

Abilities as Data, Not Code

AbilityV2 gets all its behaviour from an AbilityPattern data asset. To make a new attack you fill in that asset instead of writing ability code. One dispatcher reads the chosen shape and runs the matching routine. The player equips abilities in an Abilities Build menu and uses them from a four-slot bar on the HUD.

        case AbilityPattern.TargetType.cross:   StartCoroutine(AttackCross(...)); break;

    }
}

03

One Class, Many Different Bosses

EnemyBase handles movement, attacks, stun and confuse for every enemy, from basic enemies to bosses. EnemyBoss adds phases and ally waves on top. Three subclasses only change what makes each boss different.

EnemyBase · extends HealthSystem

The shared backbone

Movement, attacks, stun and confuse live here once, so every enemy behaves the same way on the grid.

EnemyBoss · extends EnemyBase

Phases and ally waves

Adds phases triggered by HP and waves of allies. All three bosses build on this.

Boss 01

Heraldo

Three phases triggered by HP. Before each attack he mirrors the player's row or column, so the threat always comes from where you stand.

Boss 02

Heraldo Celestial

Phase 3 is a permanent fusion: more max HP and a wider rotation of five moves, not just new attacks.

Boss 03

Computer

Invulnerable until it spawns a wave of minions. Then it only takes damage during a timed window. If you miss it, the fight resets.
